## 🚀 Getting Started

### Prerequisites
- Node.js 14+
- npm or yarn
- Database (MongoDB or PostgreSQL)
- API credentials for integrations

### Installation

```bash
# Clone the repository
git clone https://github.com/thadcornett94-glitch/Civ-ops.git
cd Civ-ops

# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Add database credentials and API keys

# Initialize database
npm run db:init

# Start development server
npm run dev

# Access at http://localhost:3000
```
